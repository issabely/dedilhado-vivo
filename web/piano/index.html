No piano o começo é encontrar as notas no teclado e usar os dedos certos. O Dedilhado Vivo mostra a tecla e o número do dedo de cada nota, acende a partitura e, com o microfone ou um teclado ligado no USB, confere se você tocou a nota certa.

Como começar no piano

  1. Ache o Dó. É a tecla branca logo à esquerda de cada grupo de duas pretas. O Dó central fica perto do meio.
  2. Numere os dedos. Polegar = 1, indicador = 2, médio = 3, anelar = 4, mínimo = 5, nas duas mãos.
  3. Posição de Dó. Mão direita com o polegar no Dó central e um dedo em cada tecla até o Sol.
  4. Primeiras músicas com cinco notas: Brilha, Brilha Estrelinha, Ode à Alegria.
  5. Passagem do polegar. Para tocar a escala inteira, o polegar passa por baixo dos outros dedos.

Perguntas frequentes

Dá para aprender piano pelo celular?

Dá para aprender as notas, os dedos e a leitura. Para praticar, use um teclado de verdade: o app ouve pelo microfone ou recebe as notas de um teclado ligado no USB.

Qual a primeira música para tocar no piano?

Brilha, Brilha Estrelinha na posição de Dó: usa só cinco teclas e um dedo para cada.

Como saber qual dedo usar no piano?

Os dedos são numerados de 1 (polegar) a 5 (mínimo). O app mostra o número do dedo em cima de cada nota da partitura.
